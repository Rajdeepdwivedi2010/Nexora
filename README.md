# NEXORA

A responsive, premium dark-themed digital utility website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — notes, task list and quick tools

## Run locally
Open `index.html` in a modern browser. No build tools or installation required.

## Included features
- Responsive landing page and navigation
- Quick notes saved in browser localStorage
- Task list with complete/delete/clear-completed
- Percentage calculator
- Word and character counter with estimated reading time

## Important
This is a front-end starter version. Notes and tasks are stored only in the current browser on the current device. They are not synced to an account or server. Clearing browser site data may remove them. Google Fonts are loaded online; system fonts will be used if unavailable.
